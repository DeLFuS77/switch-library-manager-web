## Official versions

The versions published here are built by the workflow of this repository from a tag, and their checksums (SHA256SUMS.txt) are signed with the key of this project (SHA256SUMS.txt.minisig). The images of Docker are built by the workflows of this repository too.

Only these workflows build the app with the build tag `official`. A program or an image built from this code in any other way is an unofficial build, and says that it is one.

Problems with a modified version go to whoever made it: the issues and the Discord server of this project are for the official versions.
